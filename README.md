
# DUT Rendezvous – Android Restaurant Management Application

An Android restaurant management application designed to improve daily restaurant operations and streamline interactions between customers and staff.

Developed using Kotlin and Android Studio as part of a group academic project at Durban University of Technology (DUT).

## Project Overview

### The Problem

Traditional restaurant management processes that rely on phone calls and emails can lead to communication delays, misplaced reservations and difficulties managing takeaway orders.

The aim of this project was to develop an Android application that provides customers and restaurant staff with a more convenient digital platform for managing restaurant activities.

### The Solution

The application provides separate interfaces for customers and restaurant staff, allowing users to interact with the restaurant through a mobile application.

## Main Features

### 1. Customer Interface

Customers can interact with the restaurant through the application.

Features include:

- Viewing restaurant information.
- Browsing the restaurant menu.
- Adding items to a shopping cart.
- Placing takeaway orders.
- Making restaurant reservations.
- Receiving order and reservation confirmations.

### 2. Staff Interface

The application includes a separate staff portal that provides restaurant staff with access to management-related functionality.

Features include:

- Staff login.
- Viewing incoming orders.
- Viewing reservation information.
- Accessing restaurant management features.

## Project Limitations

The application demonstrates the intended customer and staff workflows through its user interface and implemented functionality.

However, a fully integrated database has not yet been implemented. Simulated data within the application is used to demonstrate the intended functionality and user experience.
